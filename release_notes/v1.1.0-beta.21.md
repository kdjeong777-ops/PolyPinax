#### 이번 판에서 달라진 점
- **아이콘 통일** — 변환·저장 단추는 형식 배지(Word·엑셀·PPT·한글·텍스트·PDF·이미지)로, 이동 단추는 파란 가는 꺾쇠로, 이모지·글자 단추는 그린 아이콘으로 맞췄습니다. 메뉴 분류명 아이콘은 회색으로 바꿔 누르는 단추와 구분되고, 다크 모드의 메뉴 띠·분류명·스크롤 손잡이가 더 잘 보입니다. 창 나눔 막대는 점 3개 손잡이입니다.
- **꾸미기 체크 단추** — 서명 단추 왼쪽의 새 단추로 문서에 체크 표시(✓·●·✕·○)를 찍습니다. 그린 칸이 있으면 칸에 맞춰 찍고, PDF 서식 체크박스는 그 칸을 켭니다([저장] 때 반영). 서명 아이콘은 사인한 서명 곡선으로 바뀌었습니다.
- **검색** — 검색칸 옆 단추로 범위를 '지금 파일'·'폴더'로 고릅니다(기본 지금 파일). 지금 파일에 결과가 없으면 다른 파일로 옮겨 가지 않고 '검색결과 없음' 을 보여 줍니다. 결과를 키보드로 옮기면 본문이 따라가고, [?] 단추로 검색 도움말을 볼 수 있습니다. 한국어 화면에서는 대소문자 단추를 숨깁니다.
- **휠·단축키·새 창** — 절전에서 깨어난 뒤 '쪽 맞춤' 보기에서 휠로 쪽이 넘어가지 않던 결함을 고쳤습니다. 보기 탭은 Ctrl+1~9, 꾸미기 펜 색은 Ctrl+Shift+1~5 로 맞바꿨습니다(직접 바꾼 단축키는 그대로). 파일 탭 [새 창] 은 지금 보는 파일을 같은 쪽으로 새 창에 열고, Shift 를 누른 채 [폴더 열기]·[파일 열기] 를 누르면 새 창으로 엽니다. 즐겨찾기 탭의 폴더·파일 단추는 오른쪽 버튼으로 이름을 바꾸거나 지울 수 있습니다.
- **법령·특허** — 같은 법령 안에서 조문을 옮기면 다시 불러오지 않고 그 자리로 갑니다. 조문을 고른 채로도 브라우저에서 열 수 있고, 특허 🌐 는 고른 특허를 바로 보여 줍니다.
- **명함 구글 싱크** — 한국 번호를 구글에 국제 꼴(+82)로 올려 아이폰에서 +82 로 걸려 온 전화에도 이름이 뜹니다. 상대의 구글 프로필 사진만 있을 때도 명함 사진을 올립니다.

#### 이렇게 써 보세요
- 꾸미기 줄의 체크 단추로 PDF 서식의 체크박스를 눌러 보고 [저장] 해 보세요.
- 검색칸 옆 범위 단추를 '폴더' 로 바꿔 검색하고, [?] 로 도움말을 열어 보세요.
- 명함 구글 싱크를 쓰신다면 명함 환경설정에서 '인물 사진도 연락처 사진으로 주고받기' 를 켜고, 싱크 미리보기의 '구글을 명함 값으로 고침 — 전화' 를 확인한 뒤 [적용] 하세요.

#### What's new
- **Unified icons** — Convert/save buttons now use format badges (Word, Excel, PPT, HWP, text, PDF, image), move buttons use thin blue chevrons, and emoji/glyph buttons are drawn icons. Menu group icons are gray so they no longer look like buttons, and in dark mode the menu band, group labels and scroll handles are easier to see. Splitters show a three-dot grip.
- **Check button in Decorate** — A new button left of Sign stamps check marks (✓, ●, ✕, ○). It fits drawn boxes, and PDF form checkboxes are switched on (applied on Save). The Sign icon is now a signature stroke.
- **Search** — A button next to the search box picks the scope: current file or folder (current file by default). If the current file has no hits, it shows 'No results' instead of jumping to another file. Moving through results with the keyboard follows in the page, and the [?] button opens search help. The case button is hidden on the Korean interface.
- **Wheel, shortcuts, new window** — Fixed the wheel no longer turning pages in Fit Page view after waking from sleep. View tabs are now Ctrl+1–9 and decoration pen colors Ctrl+Shift+1–5 (custom shortcuts are kept). File tab [New Window] opens the current file at the same page in a new window; Shift+click [Open Folder]/[Open File] to open in a new window. Right-click a folder/file button on the Favorites tab to rename or remove it.
- **Laws and patents** — Moving between articles of the same law scrolls instead of reloading. You can open the browser with an article selected, and the patent 🌐 shows the selected patent directly.
- **Business card Google sync** — Korean numbers are uploaded to Google in international form (+82), so calls arriving as +82 on an iPhone show the contact name. Card photos are uploaded even when the contact only has a Google profile photo.

#### Try it
- Use the check button in the Decorate toolbar on a PDF form checkbox, then Save.
- Switch the scope button next to the search box to Folder, search, and open help with [?].
- If you use Google sync for business cards, turn on 'Also sync person photos as contact photos' in card settings, review the 'Update Google from cards' phone rows in the sync preview, then Apply.
